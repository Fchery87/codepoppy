# The first usable release includes inline findings

CodePoppy first serves one self-hosting owner, who supplies the GitHub App, runtime, database, runner repository, and model keys. Shadow review is an evaluation release. The first usable release posts a walkthrough and a small number of verified inline findings after qualification, because developers need review feedback where they work.

## Considered Options

- Treat the private shadow review as the first usable release.
- Publish a summary first and defer inline findings to another release.

## Consequences

- Shadow qualification remains a prerequisite for publication under ADR 0058.
- The PRD must distinguish the evaluation release from the first usable release and define acceptance for both.
- Team administration and managed hosting remain later product decisions.
